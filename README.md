# AI Healthcare & Cognitive Science Prompt Library

## Overview

A curated library of advanced prompts spanning AI in healthcare and cognitive science. Designed for AI engineers, clinicians, researchers, and policy makers, this collection covers post-authorization surveillance, FDA pathways, diagnostics, neurotechnology, ethics, red teaming, mental health, assistive tech, learning and memory, neurofeedback, and state-of-the-art AI/ML.

Use these prompts to spark research, accelerate product ideation, structure experiments, and guide responsible deployments.

## Key Features

- **Comprehensive scope:** End-to-end topics across healthcare and cognitive science, from regulation to bedside.
- **Actionable structure:** Clear context and concrete use cases for immediate application.
- **Multi-discipline by design:** Bridges AI, medicine, neuroscience, policy, and ethics.
- **Multiple styles:** Includes traditional, Leetspeak, and Super Chain Linked Leetspeak formats.
- **Real-world orientation:** Crafted for feasibility, safety, and impact.

### Post-Authorization (EUA) and Real-World Surveillance

1. **Develop a predictive analytics model for long-term safety and effectiveness of emergency-authorized drugs using real-world data.**

2. **Create an AI-driven framework to simulate clinical trial outcomes to improve predictive accuracy and reduce timelines.**
   - **Context:** Virtual trials and protocol optimization.
   - **Use Case:** Trial design and adaptive planning.

3. **Design a secure, interoperable system to integrate universal digital health records for longitudinal efficacy tracking.**
   - **Context:** Data standards and privacy-by-design.
   - **Use Case:** Cross-institutional evidence generation.

## How to Use These Prompts

- **For research planning:** Pick a prompt, expand the context to your domain, specify datasets, metrics, and expected outputs, then convert into an experiment plan.
- **For product ideation:** Translate a prompt into user stories, acceptance criteria, and risk controls; prototype and test with stakeholders.
- **Directly with LLMs:** Use this template and paste a prompt from the catalog:

```
Role: Senior [AI/Clinician/Policy/Neuro] lead
Context: [your setting, constraints, data sources]
Task: [paste prompt]
Constraints: regulatory (HIPAA/GDPR), safety, fairness, reproducibility
Output: numbered plan with assumptions, risks, datasets, eval metrics, and next steps
```
